# ValidaSenhaForte — Avaliador Didático de Senhas

-Solicita uma senha pelo console;
-Verifica as regras de validação na ordem definida;
-Informa quando uma regra não foi atendida;
-Orienta o usuário sobre como corrigir a senha;
-Permite realizar novas tentativas;
-Permite encerrar o programa digitando sair.

O projeto foi desenvolvido com foco no aprendizado de Java, estruturas condicionais, laços de repetição, Scanner, boolean e lógica de programação.
